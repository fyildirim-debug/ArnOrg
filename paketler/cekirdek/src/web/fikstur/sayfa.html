electron-updater ile özel depodan güncelleme

Electron uygulamasını özel bir GitHub deposundan güncellemek mümkündür; ama belirteci uygulamanın içine gömmek önerilmez. Bu yazıda seçenekleri karşılaştırıyoruz ve her birinin güvenlik, bakım ve maliyet açısından nerede durduğunu anlatıyoruz.

electron-builder belgeleri, Auto Update sayfasında GitHub sağlayıcısının private: true seçeneğini ve GH_TOKEN ortam değişkenini anlatır. Belirteç uygulamayla dağıtılırsa herkes depoya erişebilir; bu yüzden üretimde ara bir güncelleme sunucusu tercih edilir.

Seçenekler

YöntemBelirteç uygulamada mıNot
GitHub sağlayıcısı (private)EvetYalnız iç kullanım
Genel (generic) sunucuHayırÖnerilen
S3Hayırİmzalı adresler

Örnek yapılandırma

import { autoUpdater } from "electron-updater";

autoUpdater.setFeedURL({ provider: "generic", url: "https://guncelleme.ornek.com/" });
await autoUpdater.checkForUpdatesAndNotify();

Ayrıntılar için imzalı güncellemeler yazısına ve ilgili issue tartışmasına bakın.
