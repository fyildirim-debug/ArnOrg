# ArnOrg

Claude Code ajanlarından kurulan bir yazılım şirketi. Projeyi siz açarsınız; CEO ajanı planı yazar, ekibi işe alır, işi dağıtır ve size rapor verir.

- Windows ve Linux'ta çalışan masaüstü uygulaması + sunucu modu
- Proje başına notlar, kararlar ve hafıza; repo içinde sürümlü
- Her ajan kendi git çalışma alanında; main'e yalnız onaylı iş girer
- Kanallar, doğrudan mesaj, görev panosu, bütçe ve onay kapıları
- Ajanlar çalışırken canlı denetim: her araç çağrısı politikadan geçer, araya girilebilir, kesilebilir
