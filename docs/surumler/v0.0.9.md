ArnOrg runs Claude Code agents like a software company: you open a project and tell the CEO what you want; the CEO agent writes the plan, hires the team, hands out the work, makes the decisions and reports back to you. This release brings **Links** to the Browser: every address of your project one click away, kept current by the CEO and the team. The usage meters in the top bar now refresh every 30 seconds.

## New in 0.0.9

- **Links in the Browser.** The project addresses from 0.0.8 became **Links**, at the top of the Browser's right panel, above the notes:
  - The section is always there. When it's empty it says what it's for. **Ask the CEO** tells the CEO to add the project's links and keep them current, **+** lets you add one yourself, and every card has a remove button.
  - The CEO runs the list. Whenever the project has an address that can be opened (dev server, API and its docs, preview, staging or live site, admin panel), the CEO adds it with a short, clear name, updates it when it changes and removes it when it's no longer used. When a task produces a page or a server, the CEO has the employee register its address.
  - Employees register the servers they start, and register lasting addresses as lasting. ArnOrg still picks up lines like `Local: http://localhost:5173` from their output.
  - Links that the CEO or you add, and addresses outside your network, are lasting: they stay until someone removes them, even while the server is down. A temporary server address drops off a few minutes after the server stops.
  - Click a link to open it in the in-app browser. While the browser is empty, the links also show there as buttons with their names.
- **Usage every 30 seconds.** The 5-hour and weekly percentages in the top bar refresh every 30 seconds instead of every 5 minutes. When no agent is running, ArnOrg keeps one quiet Claude Code process open for this instead of starting a new one for every reading; it uses no tokens. After repeated errors it waits 1, 2 and then 5 minutes between tries.
- **Linux packages** describe the shared way of working that 0.0.8 introduced.

## Requirements

- **A Claude subscription** (Pro, Max or Team). ArnOrg only works with a subscription; it doesn't use API keys.
- The first-run assistant takes care of the Claude Code sign-in, git and the GitHub CLI. On Windows, Git for Windows is recommended.

## Good to know

- **After updating,** press **Ask the CEO** once in each project's Browser so the CEO fills in the Links right away; from then on the CEO keeps them current.
- **Updating from 0.0.6, 0.0.7 or 0.0.8** happens by itself. **From 0.0.5,** download and install this version once from the [Releases](https://github.com/fyildirim-debug/ArnOrg/releases) page; your projects, settings and sign-ins are kept.
- The installers are unsigned. On the Windows SmartScreen prompt choose **More info → Run anyway**.
- The AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Data: `%APPDATA%\ArnOrg` on Windows, `~/.config/ArnOrg` on Linux. Uninstalling doesn't remove user data.

## Türkçe

ArnOrg, Claude Code ajanlarını bir yazılım şirketi gibi çalıştırır: projeyi siz açar, ne istediğinizi CEO'ya anlatırsınız; CEO ajanı planı yazar, ekibi işe alır, işi dağıtır, kararları verir ve size rapor verir. Bu sürüm Tarayıcı'ya **Linkler**'i getiriyor: projenizin bütün adresleri tek tık uzakta, CEO ve ekip güncel tutar. Üst çubuktaki kullanım ölçerleri artık 30 saniyede bir tazelenir.

### 0.0.9'da yeni

- **Tarayıcı'da Linkler.** 0.0.8'deki proje adresleri artık **Linkler**: Tarayıcı'nın sağ panelinin üstünde, notların üstünde:
  - Alan her zaman görünür. Boşken ne işe yaradığını söyler. **CEO'dan iste** CEO'ya projenin linklerini eklemesini ve güncel tutmasını söyler, **+** ile kendiniz link eklersiniz, her kartta kaldırma düğmesi vardır.
  - Listeyi CEO yönetir. Projenin açılabilen bir adresi olduğunda (geliştirme sunucusu, API ve dokümanı, önizleme, test ya da canlı yayın, yönetim paneli) CEO onu kısa ve açık bir adla ekler, değişince günceller, kullanılmayınca kaldırır. Bir görev sayfa ya da sunucu üretiyorsa CEO çalışana adresini bildirtir.
  - Çalışanlar başlattıkları sunucuları bildirir, kalıcı adresleri kalıcı olarak bildirir. ArnOrg çıktılarındaki `Local: http://localhost:5173` gibi satırları yine kendisi yakalar.
  - CEO'nun ya da sizin eklediğiniz linkler ve ağınızın dışındaki adresler kalıcıdır: sunucu kapalı olsa da biri kaldırana dek durur. Geçici bir sunucu adresi, sunucu kapandıktan birkaç dakika sonra listeden düşer.
  - Linke tıklayınca uygulama içi tarayıcıda açılır. Tarayıcı boşken linkler orada da adlarıyla düğme olarak görünür.
- **Kullanım 30 saniyede bir.** Üst çubuktaki 5 saatlik ve haftalık yüzdeler 5 dakika yerine 30 saniyede bir tazelenir. Çalışan ajan yokken ArnOrg her okumada yeni bir Claude Code süreci açmak yerine bunun için sessiz bir süreci açık tutar; token harcanmaz. Okuma üst üste hata verirse denemeler arasında 1, 2 ve sonra 5 dakika bekler.
- **Linux paketleri** 0.0.8'le gelen ortak çalışma düzenini anlatır.

### Gerekenler

- Kurulum dosyaları imzasızdır. Windows SmartScreen uyarısında **Ek bilgi → Yine de çalıştır** seçin.
- AppImage için FUSE 2 gerekir (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Veriler: Windows'ta `%APPDATA%\ArnOrg`, Linux'ta `~/.config/ArnOrg`. Kaldırma kullanıcı verisini silmez.
