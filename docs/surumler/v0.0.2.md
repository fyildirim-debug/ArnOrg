ArnOrg runs Claude Code agents like a software company: you open a project and give a brief; the CEO agent writes the plan, hires the team, hands out the work and reports back to you. This release adds a guided first run, GitHub integration, a constitution, agents that remember who they are, a global intelligence that learns across projects, and English.

## New in 0.0.2

- **Guided first run.** The CEO walks you through setup:
  - Claude Code: installed for you if it's missing; sign in through the browser and paste the code back if asked.
  - git and your git identity.
  - The GitHub CLI: downloaded for you, browser sign-in with a one-time code, set up as git's credential helper.
  - Where projects live and the language.

  A preparation talk follows: goals, preferences, the constitution, the first hires and the first plan.
- **Projects without typing paths.**
  - New projects go to `~/ArnOrg/<name>`.
  - An existing folder opens with the system folder picker.
  - **Open from GitHub**: pick a repository and branch, and ArnOrg clones it.
  - ArnOrg can create the GitHub repository (private or public).
  - Pick the working branch, keep in sync with GitHub (pull, and push automatically if you like).
- **Constitution.** Drafted with the CEO and approved by you; every agent, the CEO included, follows it. Machine-checkable articles are enforced at the gate before anything else, and agents are reminded when it changes.
- **Agents that don't forget.**
  - Each employee has:
    - a small personal memory;
    - promises they make and keep;
    - team skills;
    - search over past conversations;
    - memory hand-over to teammates.
  - Hooks remind agents of who they are, their work, their promises and the constitution: every 25 tool calls or 30 minutes, and after context compaction.
  - News from teammates arrives on the next turn.
- **Global intelligence.** Rules learned across projects from your preferences, corrections and the lessons agents write down. A candidate rule becomes a standard with evidence or once it shows up in a second project; duplicates merge, weak rules retire. Each agent gets the rules in its role and authority. You can review, edit or switch off any rule on the new **Intelligence** screen.
- **Headquarters and channels.**
  - A one-to-one chat with the CEO in #ceo.
  - Channels update live, with typing indicators and clickable links.
  - #general announces when work starts, goes to review and finishes.
- **Approvals.** A clearer ledger: reasoning, details and what happens if you approve. New types: constitution, dismissal, delivery. An **Auto-approve** checkbox that you can limit to chosen types.
- **Important moments reach you anywhere.** A pop-up on every screen for approvals, proposals, requests and deliveries. When the window is in the background you also get a desktop notification and the taskbar flashes.
- **A team that changes over time.** The CEO can hire or propose a dismissal later in the project. A dismissal needs your approval; work, promises and notes pass to a successor.
- **Delivery.** When the project is done, the CEO hands it over with test steps, the run command and the address. Your feedback goes back to the CEO as work.
- **Office.**
  - People stay where they were when you come back to the screen or reload.
  - They go to the place that fits the work: coding at the desk, planning at the board, meetings in the meeting room, pushes at the server rack, research in the reading corner.
  - Monitors now face the person at the desk.
- **English.** The interface and the agents work in English or Turkish, as you choose. The README is now in English, with a Turkish copy.

## Requirements

- **A Claude subscription** (Pro, Max or Team). ArnOrg only works with a subscription; it doesn't use API keys.
- The first-run assistant takes care of the Claude Code sign-in, git and the GitHub CLI. On Windows, Git for Windows is recommended.

## Good to know

- The installers are unsigned. On the Windows SmartScreen prompt choose **More info → Run anyway**.
- The AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- The semantic code search model downloads on first use (about 310 MB). In Settings you can switch to a smaller model or turn it off.
- Data: `%APPDATA%\ArnOrg` on Windows, `~/.config/ArnOrg` on Linux. Uninstalling doesn't remove user data. Upgrading from 0.0.1 keeps your projects and adds the new channels and settings automatically; the first-run assistant opens once so you can set up GitHub and the language.

### 0.0.2'de yeni

- **Yönlendirmeli ilk açılış.** CEO kurulumda size eşlik eder:
  - Claude Code: yoksa ArnOrg kurar; giriş tarayıcıdan yapılır, istenirse kod yapıştırılır.
  - git ve git kimliğiniz.
  - GitHub CLI: ArnOrg indirir, tarayıcıdan tek kullanımlık kodla giriş yapılır, git'in kimlik yardımcısı olarak ayarlanır.
  - Projelerin duracağı yer ve dil.

  Ardından hazırlık görüşmesi: amaç, tercihler, ana yasa, ilk işe alımlar ve ilk plan.
- **Yol yazmadan proje.**
  - Yeni proje `~/ArnOrg/<ad>` altına açılır.
  - Var olan klasör sistemin klasör seçicisiyle açılır.
  - **GitHub'dan aç**: depoyu ve dalı seçersiniz, ArnOrg indirir.
  - GitHub'da depoyu ArnOrg açabilir (özel ya da açık).
  - Çalışma dalını seçersiniz; proje GitHub ile eşit kalır (çekme; isterseniz otomatik gönderme).
- **Ana yasa.** Yönetici ile hazırlanır, siz onaylarsınız; CEO dahil her ajan uyar. Makinenin denetleyebildiği maddeler denetim kapısında her şeyden önce uygulanır; yasa değişince ajanlara hatırlatılır.
- **Unutmayan ajanlar.**
  - Her çalışanın şunları vardır:
    - küçük bir kişisel hafıza;
    - verip tuttuğu sözler;
    - ekip becerileri;
    - geçmiş konuşmalarda arama;
    - ekip arkadaşına hafıza aktarımı.
  - Kancalar kimliği, işi, sözleri ve ana yasayı hatırlatır: her 25 araç çağrısında ya da 30 dakikada bir, bir de bağlam sıkıştırılınca.
  - Ekipten haberler bir sonraki turda gelir.
- **Global zekâ.** Projelerden bağımsız öğrenilen kurallar; kaynakları tercihleriniz, düzeltmeleriniz ve ajanların yazdığı derslerdir. Aday kural kanıtla ya da ikinci bir projede görülünce standart olur; tekrar edenler birleşir, zayıflar emekliye ayrılır. Her ajan rolü ve yetkisi kapsamındaki kuralları alır. Yeni **Zekâ** ekranında her kuralı görebilir, düzenleyebilir ya da kapatabilirsiniz.
- **Karargâh ve kanallar.**
  - #yonetim'de CEO ile bire bir sohbet.
  - Kanallar canlı akar; yazıyor göstergesi ve tıklanabilir bağlantılar var.
  - #genel, işin başladığını, incelemeye girdiğini ve bittiğini duyurur.
- **Onaylar.** Daha okunaklı defter: gerekçe, ayrıntı ve onaylanırsa ne olacağı. Yeni türler: ana yasa, işten çıkarma, teslim. Seçtiğiniz türlerle sınırlanabilen **Otomatik onay** kutusu.
- **Önemli anlar her ekranda.** Onay, öneri, istek ve teslimde her ekranda açılır pencere. Pencere arkadaysa masaüstü bildirimi de gelir ve görev çubuğu yanıp söner.
- **Zamanla değişen ekip.** CEO projenin ilerleyen döneminde işe alım yapabilir ya da işten çıkarma önerebilir. İşten çıkarma sizin onayınızla olur; işler, sözler ve notlar devralana geçer.
- **Teslim.** Proje bitince CEO test adımları, çalıştırma komutu ve adresle teslim eder. Geri bildiriminiz CEO'ya iş olarak döner.
- **Ofis.**
  - Ekrana dönünce ya da sayfayı yenileyince herkes bıraktığınız yerde.
  - Çalışanlar işe uygun yere gider: kod masada, planlama panoda, toplantı toplantı odasında, gönderim sunucu dolabında, araştırma okuma köşesinde.
  - Monitörler artık masadaki kişiye bakıyor.
- **İngilizce.** Arayüz ve ajanlar seçtiğiniz dilde (Türkçe ya da İngilizce) çalışır. README artık İngilizce; Türkçesi ayrı dosyada.

### Gerekenler

- **Claude aboneliği** (Pro, Max ya da Team). ArnOrg yalnız abonelikle çalışır; API anahtarı kullanmaz.
- Claude Code girişini, git'i ve GitHub CLI'ı ilk açılış asistanı halleder. Windows'ta Git for Windows önerilir.

### Bilinmesi gerekenler

- Kurulum dosyaları imzasızdır. Windows SmartScreen uyarısında **Ek bilgi → Yine de çalıştır** seçin.
- AppImage için FUSE 2 gerekir (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Anlamsal kod aramasının modeli ilk kullanımda indirilir (yaklaşık 310 MB); Ayarlar'dan daha küçük modele geçilebilir ya da kapatılabilir.
- Veriler: Windows'ta `%APPDATA%\ArnOrg`, Linux'ta `~/.config/ArnOrg`. Kaldırma kullanıcı verisini silmez. 0.0.1'den yükseltmede projeleriniz korunur, yeni kanallar ve ayarlar kendiliğinden eklenir; GitHub'ı ve dili ayarlayabilmeniz için ilk açılış asistanı bir kez açılır.
