ArnOrg runs Claude Code agents like a software company: you open a project and give a brief; the CEO agent writes the plan, hires the team, hands out the work and reports back to you. This release makes sure a missing or expired Claude Code sign-in never quietly stops your company: whichever screen you're on, ArnOrg tells you and helps you fix it.

## New in 0.0.3

- **A Claude Code assistant on every screen.** If Claude Code isn't installed, isn't signed in, or is signed in without a subscription, a thin bar under the top bar says so on every screen. Its button opens the Claude Code setup in a side drawer:
  - install Claude Code;
  - sign in through the browser, pasting the code back if asked;
  - check the subscription.

  The drawer closes by itself once everything is green. **Later** hides the bar until the problem comes back.
- **Agents wait instead of failing.** When an agent's session hits a sign-in or subscription error, the session stops cleanly. The agent shows *Paused · Waiting for Claude Code sign-in* instead of an error. A pop-up with a **Sign in to Claude Code** button appears on whichever screen you're on, at most once every 10 minutes.
- **They pick up where they left off.** As soon as you sign in, from ArnOrg or from a terminal, the waiting agents continue the same conversation. While agents wait, ArnOrg checks the sign-in once a minute, so a terminal sign-in is noticed even when the ArnOrg window isn't open.
- **Claude Code installs even without a bundled copy.** If no Claude Code is found at all, ArnOrg installs it into your user folder with Anthropic's official install script. No admin rights are needed, but an internet connection is. The drawer shows the progress.
- **Sign in again.** Even when everything looks fine, the setup offers a *Sign in again* link: for a sign-in that expired on the server, or to switch accounts.
- Pop-ups and the sliding live rail now start below the warning bar, so its buttons stay visible.

## Requirements

- **A Claude subscription** (Pro, Max or Team). ArnOrg only works with a subscription; it doesn't use API keys.
- The first-run assistant takes care of the Claude Code sign-in, git and the GitHub CLI. On Windows, Git for Windows is recommended.

## Good to know

- The installers are unsigned. On the Windows SmartScreen prompt choose **More info → Run anyway**.
- The AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Data: `%APPDATA%\ArnOrg` on Windows, `~/.config/ArnOrg` on Linux. Uninstalling doesn't remove user data. Upgrading from 0.0.2 keeps your projects, settings and sign-ins.

### 0.0.3'te yeni

- **Her ekranda Claude Code asistanı.** Claude Code kurulu değilse, giriş yapılmamışsa ya da abonelik dışı bir girişle açılmışsa her ekranda üst çubuğun altında ince bir şerit bunu söyler. Şeridin düğmesi Claude Code kurulumunu yandan açılan çekmecede açar:
  - Claude Code'u kurma;
  - tarayıcıdan giriş, istenirse kodu yapıştırma;
  - aboneliği denetleme.

  Her şey yeşile dönünce çekmece kendiliğinden kapanır. **Sonra**, sorun yeniden çıkana kadar şeridi gizler.
- **Ajanlar hata vermek yerine bekler.** Bir ajanın oturumu giriş ya da abonelik hatası alınca oturum düzgünce kapanır. Ajan hata yerine *Duraklatıldı · Claude Code girişi bekleniyor* gösterir. Hangi ekranda olursanız olun **Claude Code'a giriş yap** düğmeli bir açılır pencere gelir; en çok 10 dakikada bir.
- **Kaldıkları yerden sürerler.** Giriş yapar yapmaz, ArnOrg'dan ya da terminalden, bekleyen ajanlar aynı konuşmayı sürdürür. Ajanlar beklerken ArnOrg girişi dakikada bir denetler; ArnOrg penceresi açık olmasa da terminalden yapılan giriş fark edilir.
- **Paketle gelen kopya yoksa da Claude Code kurulur.** Hiç Claude Code bulunamazsa ArnOrg onu Anthropic'in resmî kurulum betiğiyle kullanıcı dizininize kurar. Yönetici izni gerekmez, internet bağlantısı gerekir. Çekmece ilerlemeyi gösterir.
- **Yeniden giriş.** Her şey yolunda görünse de kurulumda *Yeniden giriş yap* bağlantısı vardır: sunucuda süresi dolan bir giriş için ya da hesap değiştirmek için.
- Açılır pencereler ve kayan canlı ray artık uyarı şeridinin altından başlar; şeridin düğmeleri görünür kalır.

### Gerekenler

- **Claude aboneliği** (Pro, Max ya da Team). ArnOrg yalnız abonelikle çalışır; API anahtarı kullanmaz.
- Claude Code girişini, git'i ve GitHub CLI'ı ilk açılış asistanı halleder. Windows'ta Git for Windows önerilir.

### Bilinmesi gerekenler

- Kurulum dosyaları imzasızdır. Windows SmartScreen uyarısında **Ek bilgi → Yine de çalıştır** seçin.
- AppImage için FUSE 2 gerekir (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Veriler: Windows'ta `%APPDATA%\ArnOrg`, Linux'ta `~/.config/ArnOrg`. Kaldırma kullanıcı verisini silmez. 0.0.2'den yükseltmede projeleriniz, ayarlarınız ve girişleriniz korunur.
