İlk sürüm. ArnOrg, Claude Code ajanlarını bir yazılım şirketi gibi çalıştıran masaüstü uygulamasıdır: projeyi siz açar, brief verirsiniz; CEO ajanı planı yazar, ekibi işe alır, işi dağıtır ve size rapor verir. Her ajanın her araç çağrısı ArnOrg'un denetiminden geçer.

## İndirme

| Sistem | Dosya | Kurulum |
|---|---|---|
| Windows 10/11 · x64 | `ArnOrg-Kurulum-0.0.1-x64.exe` | Önerilen. Türkçe kurulum sihirbazı; kurulum dizini seçilebilir |
| Windows · x64, kurumsal dağıtım | `ArnOrg-0.0.1-x64.msi` | Toplu kurulum için |
| Linux · x64, her dağıtım | `ArnOrg-0.0.1-x86_64.AppImage` | Kurulumsuz: `chmod +x` ile çalıştırılabilir yapıp açın |
| Debian, Ubuntu · x64 | `ArnOrg-0.0.1-amd64.deb` | `sudo apt install ./ArnOrg-0.0.1-amd64.deb` |
| Fedora, RHEL, openSUSE · x64 | `ArnOrg-0.0.1-x86_64.rpm` | `sudo dnf install ./ArnOrg-0.0.1-x86_64.rpm` |
| Linux · arm64 | `ArnOrg-0.0.1-arm64.AppImage`, `ArnOrg-0.0.1-arm64.deb`, `ArnOrg-0.0.1-aarch64.rpm` | x64 ile aynı |

`latest*.yml` ve `.blockmap` dosyaları güncelleme içindir, indirmeniz gerekmez.

## Gerekenler

- **Claude aboneliği** (Pro, Max ya da Team). ArnOrg yalnız abonelikle çalışır; API anahtarı kullanmaz.
- **Claude Code girişi:** Claude Code'u kurup terminalde bir kez `claude` açın ve `/login` ile claude.ai hesabınızla giriş yapın. Ajanlar bu girişi kullanır.
- **git.** Windows'ta Git for Windows önerilir; Claude Code'un kabuk aracı Git Bash ile çalışır.

## Bu sürümde

- **Şirket:** proje açma ya da var olan repoyu bağlama; CEO brief'ten plan çıkarır, işe alım teklif eder, görevleri dağıtır, dönem raporu yazar. İşe alım ve main'e birleştirme yönetim kurulu (siz) onayıyla olur.
- **Git düzeni:** her ajan kendi git çalışma alanında ve dalında çalışır; main'e yalnız onaylanan iş girer. Ajan commit'leri sizin git kimliğinizle atılır; Claude imzası eklenmez.
- **Canlı denetim:** yıkıcı komut, gizli dosya, alan dışına yazma ve dışarı push kuralları; araya girme, kesme, karar bekleyen çağrılar.
- **Ekip iletişimi:** kanallar, `@anma` ile uyandırma, görev panosu, onaylar, tıkanan iş için hatırlatma ve yükseltme.
- **Ofis:** şirketin canlı 2D hâli; kişiliği, konuşma üslubu ve ofiste sevdiği yeri olan 32 karakter.
- **Proje hafızası:** kurul tercihleri, kararlar, öğrenilen hatalar ve ajan defterleri repo içinde `.arnorg/` altında; ajanlar arası sorular ve toplantılar.
- **Kod zekâsı:** kod tarayıcı, sembol ve bağımlılık haritası, Türkçe ya da İngilizce doğal dille anlamsal kod arama. Model makinede çalışır, kod dışarı gitmez.
- **Kod:** yerleşik VS Code tezgâhı (Türkçe); ana repo ve her ajan çalışma alanı, terminal, arama, kaynak denetimi.
- **Kullanım:** token ve aboneliğin 5 saatlik ve haftalık pencere yüzdeleri; ajanlar kurulun belirlediği yüzdede durur, pencere açılınca kaldıkları yerden sürer.

## Bilinmesi gerekenler

- Kurulum dosyaları imzasızdır. Windows SmartScreen uyarısında **Ek bilgi → Yine de çalıştır** seçin.
- AppImage için FUSE 2 gerekir (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Anlamsal kod aramasının modeli ilk kullanımda indirilir (yaklaşık 310 MB); Ayarlar'dan daha küçük modele geçilebilir ya da kapatılabilir.
- Veriler: Windows'ta `%APPDATA%\ArnOrg`, Linux'ta `~/.config/ArnOrg`. Kaldırma kullanıcı verisini silmez.
