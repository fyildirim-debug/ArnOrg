ArnOrg runs Claude Code agents like a software company: you open a project and give a brief; the CEO agent writes the plan, hires the team, hands out the work and reports back to you. With this release ArnOrg is open source under the MIT license, and installed apps update straight from this repository.

## Download

| System | File | Install |
|---|---|---|
| Windows 10/11 · x64 | `ArnOrg-Kurulum-0.0.6-x64.exe` | Recommended. Setup wizard; you can choose the install folder |
| Windows · x64, managed deployment | `ArnOrg-0.0.6-x64.msi` | For bulk installs (no automatic updates) |
| Linux · x64, any distribution | `ArnOrg-0.0.6-x86_64.AppImage` | No install: make it executable with `chmod +x` and run it |
| Debian, Ubuntu · x64 | `ArnOrg-0.0.6-amd64.deb` | `sudo apt install ./ArnOrg-0.0.6-amd64.deb` |

| Linux · arm64 | `ArnOrg-0.0.6-arm64.AppImage`, `ArnOrg-0.0.6-arm64.deb`, `ArnOrg-0.0.6-aarch64.rpm` | Same as x64 |

The `latest*.yml` and `.blockmap` files are for updates; you don't need to download them.

## New in 0.0.6

- **Open source.** The source code is public under the [MIT license](https://github.com/fyildirim-debug/ArnOrg/blob/main/LICENSE). Issues and pull requests are welcome.
- **Updates come from this repository.** Installed apps look for new versions in this repository's releases; there is no separate releases repository any more.
  - Versions 0.0.1 to 0.0.4 already look here and update themselves.
  - **0.0.5 looked in a releases repository that was never set up. Install 0.0.6 by hand once**; later versions arrive by themselves.
- **Ready for Windows code signing.** As soon as a signing certificate is configured, the release workflow signs the app, the uninstaller, the setup wizard and the MSI:
  - SSL.com eSigner, DigiCert KeyLocker and other signing tools are supported. The private key stays in the provider's cloud HSM and never enters the repository.
  - Every signature is checked before the release is published, so a release that should be signed is never published unsigned.
  - This release is still unsigned.
- **Menu links** (Documents, Releases, Report a problem) open this repository.

## Requirements

- **A Claude subscription** (Pro, Max or Team). ArnOrg only works with a subscription; it doesn't use API keys.
- The first-run assistant takes care of the Claude Code sign-in, git and the GitHub CLI. On Windows, Git for Windows is recommended.

## Good to know

- **Updating from 0.0.5:** download and install 0.0.6 once from the [Releases](https://github.com/fyildirim-debug/ArnOrg/releases) page. Your projects, settings and sign-ins are kept.
- The installers are unsigned. On the Windows SmartScreen prompt choose **More info → Run anyway**.
- The AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
- Data: `%APPDATA%\ArnOrg` on Windows, `~/.config/ArnOrg` on Linux. Uninstalling doesn't remove user data.

### 0.0.6'da yeni

- **Açık kaynak.** Kaynak kod [MIT lisansıyla](https://github.com/fyildirim-debug/ArnOrg/blob/main/LICENSE) herkese açık. Sorun kayıtları ve çekme istekleri açıktır.
- **Güncellemeler bu depodan gelir.** Kurulu uygulamalar yeni sürümü bu deponun sürümlerinde arar; ayrı bir sürüm deposu artık yok.
  - 0.0.1–0.0.4 zaten buraya bakar ve kendini günceller.
  - **0.0.5 hiç kurulmamış bir sürüm deposuna bakıyordu. 0.0.6'yı bir kez elle kurun**; sonraki sürümler kendiliğinden gelir.
- **Windows kod imzasına hazır.** İmza sertifikası tanımlanır tanımlanmaz sürüm iş akışı uygulamayı, kaldırıcıyı, kurulum sihirbazını ve MSI'ı imzalar:
  - SSL.com eSigner, DigiCert KeyLocker ve başka imza araçları desteklenir. Gizli anahtar sağlayıcının bulut HSM'inde kalır, depoya hiç girmez.
  - Her imza yayından önce doğrulanır; imzalı olması gereken bir sürüm imzasız yayınlanmaz.
  - Bu sürüm henüz imzasızdır.
- **Menü bağlantıları** (Belgeler, Sürümler, Sorun bildir) bu depoyu açar.
